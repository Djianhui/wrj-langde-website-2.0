民用航空安防

某国际机场低空防御系统部署项目

项目概览

calendar_today 项目时间

location_on 应用地点

华东地区核心国际枢纽机场

memory 部署产品

  • L-Band 低空安防雷达阵列
  • LD-900 智能光电跟踪系统
  • 全频段定向电磁干扰设备

负责团队

朗德智能华东交付中心

warning 核心背景与需求

随着消费级无人机的普及，机场净空保护区频繁遭遇不明飞行物（"黑飞"）侵入，严重威胁航空器起降安全。该国际机场原有安防手段依赖人工巡视，存在发现难、定位慢、处置手段单一等问题。客户急需一套能够全天候、全方位、自动化探测并反制非法无人机的综合性低空防御系统。

verified_user 朗德智能解决方案

针对机场环境的复杂电磁背景和超大防区需求，朗德智能部署了"雷达+光电+无线电侦测"的多维异构传感网络。通过自研的边缘计算核心，实现对微小目标的精准识别与轨迹融合。

  • check_circle 分布式雷达组网：在航站楼顶及跑道两端部署3台阵列雷达，实现无死角覆盖。
  • check_circle AI视觉联动：雷达发现目标后，引导远距离光电球秒级锁定，提供高清视觉证据。
  • check_circle 智能指挥中枢：接入机场安保控制中心，实现一键报警、自动评估威胁等级并推荐反制策略。
